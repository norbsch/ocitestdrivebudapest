# p01 OKE környezet adatai

A guide-ot sorban kövesd. Ezeket az adatokat a résztvevő Cloud Shell-kimenete igazolta; nem a csomag fejlesztője csatlakozott a clusterhez.

| Mező | Érték |
| --- | --- |
| Régió | `eu-frankfurt-1` |
| Compartment | `OCITestDriveBudapest` |
| VCN | `p01-vcn` |
| Cluster neve | `p01-oke` |
| Cluster OCID | `ocid1.cluster.oc1.eu-frankfurt-1.aaaaaaaamb5yuvqydxeaenngqm2o65rpu73kzsc5ht6co54x2cnhkvcst2pq` |
| Cluster típusa | Basic |
| Kubernetes | `v1.37.1` |
| Architektúra | `amd64` |
| Worker shape | `VM.Standard.E5.Flex` |
| Ellenőrzéskori worker IP-k | `10.0.1.149`, `10.0.1.200`, `10.0.1.227` |
| Privát API-végpont | `10.0.0.168:6443` |
| Kubeconfig context | `context-p01-oke-cnhkvcst2pq` |
| Cloud Shell | A p01 VCN-t elérő Private Network Access |
| App NodePort, alapérték | `30080` |

A Public Network + public API végpont felállás időtúllépést adott. A privát hálózatra és privát API-végpontra váltás után mindhárom worker Ready állapotban látszott. Az új guide ezt a működő elérést használja.

A megfigyelt clusterben nincs IngressClass, Ingress vagy alkalmazás LoadBalancer Service. Ezért a külön csomag `NodePort` Service-t készít, a kolléga meglévő OCI Load Balancerébe a worker node-ok aktuális privát IP-je és a választott NodePort kerül kézzel. Ez a három backend továbbra is egyetlen Streamlit-podot szolgál ki.

A PostgreSQL-cím, CA, adminadatok, külön alkalmazás-DB és -user, OCIR tenancy namespace/username, GenAI-adatok, LB neve/címe/listenere a saját infrastruktúrából kitöltendő. Nem kell hozzájuk a korábbi VM-es demókörnyezet credentialjeit átmásolni.

A worker IP-k idővel változhatnak. Az LB backendlistájához mindig a `kubectl get nodes -o wide` aktuális INTERNAL-IP értékeit használd.
